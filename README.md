# ANALISE-INCENDIOS-FLORESTAIS
 Análise de Incêndios Florestais *EM ANDAMENTO*

Projeto de análise de dados sobre incêndios florestais no Brasil, desenvolvido em Python.

 Objetivo

Analisar dados históricos de incêndios florestais para identificar padrões e compreender a ocorrência de focos de incêndio ao longo dos anos, meses e estados brasileiros.

📊 Dados

O projeto utiliza um conjunto de dados contendo informações sobre:

Ano
Estado
Mês
Número de incêndios
Data

🐍 Tecnologias
Python
Pandas
Matplotlib
🔎 Análises

Durante o desenvolvimento do projeto serão analisados:

Quantidade de incêndios por ano;
Quantidade de incêndios por estado;
Quantidade de incêndios por mês;
Períodos com maior ocorrência;
Evolução dos incêndios ao longo dos anos;
Comparação entre estados e períodos.

📈 Visualização

Os resultados serão apresentados por meio de gráficos para facilitar a identificação de padrões e tendências nos dados.
